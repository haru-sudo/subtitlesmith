プライバシーポリシー

最終更新日: 2026年6月9日

「subtitlesmith」（以下「本サービス」）は、許可された利用者のみが利用する 動画・字幕管理ツールです。本サービスにおける個人情報・データの取り扱いについて、以下のとおり定めます。

1. 取得する情報

  • ログイン認証のために、メールアドレス（外部アカウントでログインする場合は、そのプロフィールの基本情報）
  • 利用者がアップロードした動画・音声、および本サービスが生成した文字起こし・翻訳・字幕データ

2. 利用目的

  • 許可された利用者であることの確認（ログイン認証）
  • 字幕の自動生成・翻訳・編集・管理

3. 外部サービスへの送信

文字起こし・翻訳・類似検索のため、音声・テキストを、設定された外部 API（Anthropic・OpenAI・Google Gemini・Deepgram など）に送信する場合があります。 これらは当該処理の目的にのみ使用します。

4. 第三者提供

上記の処理に必要な範囲を除き、取得した情報を第三者へ販売・提供することはありません。

5. 管理・保管

データはサーバー上に保管し、許可された利用者のみがアクセスできます。不要となったデータは利用者が削除できます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、運営者までご連絡ください。
